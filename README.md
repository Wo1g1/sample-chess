# 6×6 변형 체스

AI와 대결할 수 있는 변형 체스 게임입니다.

## 🎮 플레이하기

GitHub Pages에서 바로 플레이: [여기를 클릭](https://wo1g1.github.io/sample-chess/)

## 🎯 특징

- **AI 대결 모드**: 미니맥스 알고리즘 기반 AI와 대결
- **혼자서 두기 모드**: 백과 흑을 번갈아가며 플레이
- **특수 기물**: 리퍼(Leaper) - 기물을 뛰어넘을 수 있는 특수 기물
- **폰 승격**: 상대편 끝줄에 도달한 폰은 장군(General)으로 승격

## 🔧 로컬 실행

이 프로젝트는 단일 HTML 파일로 구성되어 있어 별도의 빌드 과정 없이 실행할 수 있습니다.

1. 리포지토리 클론
```bash
git clone https://github.com/Wo1g1/sample-chess.git
cd sample-chess
```

2. 로컬 서버 실행 (Python 사용)
```bash
python3 -m http.server 8000
```

3. 브라우저에서 `http://localhost:8000` 접속

## 🐛 디버깅

브라우저 개발자 도구의 콘솔을 열면 AI의 계산 과정과 성능을 확인할 수 있습니다:
- AI 차례 시작 로그
- 계산 시간 (밀리초)
- 평가 점수와 선택된 수

## 📝 최근 변경사항

### 성능 개선
- AI 탐색 깊이를 3에서 2로 축소하여 응답 속도 개선
- 디버깅 로그 추가로 AI 동작 추적 가능
- useEffect 의존성 문제 해결

### 버그 수정
- AI가 플레이어의 첫 수 이후 응답하지 않던 문제 해결
- React Hook 의존성 문제 수정
